# dotfiles

this repo is for my dotfiles and my personal use. feel free to take a look.

## Stow

for applying any of the dotfiles, run this command:

```
  stow --dotfiles [SOFTWARE_NAME] -d /path/to/this/dir -t $HOME
```

###### if this directory is in the user's home directory, you can omit `-t $HOME` option

###### if you are in this directory, you can omit `-d /path/to/this/dir` option
